# Objetivo

Explorar o portal do DiOE de Avaré e desenvolver um scraper inicial em Python.

# Fonte utilizada

https://imprensaoficialmunicipal.com.br/avare

# Ferramentas utilizadas

- Python
- requests
- BeautifulSoup
- pandas

# Estrutura identificada

- Publicações organizadas em blocos
- Possíveis links para PDFs
- Informações de data e título

# Script desenvolvido

Arquivo:
scraper.py

Funções:
- acessar o portal
- coletar publicações
- gerar CSV automático

# Execução

python scraper.py

# Resultado

Geração do arquivo:
diario_avare.csv

Com mínimo de 20 registros.

# Conclusão

Foi possível realizar a exploração inicial do portal do Diário Oficial Eletrônico de Avaré e desenvolver um coletor automatizado funcional.
